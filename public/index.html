Guide de Publication et de Déploiement

Votre application Helpdesk & Incident Tracker Pro est contenue dans un seul fichier HTML autonome et mis à jour. Voici les méthodes les plus simples et rapides pour la publier et la partager avec toute votre équipe :

Option 1 : GitHub Pages (Gratuit, Professionnel & Permanent)

  1. Créez un compte ou connectez-vous sur GitHub.
  2. Créez un nouveau dépôt (Repository) public nommé par exemple issue-tracker.
  3. Enregistrez votre code actuel sous le nom exact index.html et déposez-le (Add file > Upload files).
  4. Allez dans les paramètres de votre dépôt (**Settings** > **Pages**).
  5. Sous Build and deployment > Branch, sélectionnez main et cliquez sur **Save**.
  6. En moins d'une minute, GitHub vous fournira un lien web officiel accessible par tous vos collègues !

Option 2 : Netlify Drop (Le plus rapide en 1 clic - 30 secondes)

  1. Téléchargez et enregistrez ce fichier HTML sur votre ordinateur sous le nom index.html.
  2. Rendez-vous sur le site gratuit Netlify Drop.
  3. Glissez-déposez (Drag & Drop) votre fichier index.html directement dans la zone indiquée sur la page.
  4. Netlify génère instantanément un lien sécurisé partageable.
